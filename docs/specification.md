- **프로젝트:** 월드맵 위치에 개인 메모를 핀으로 고정하는 WoW 애드온.
- **목적 (Why):**
  - 플레이 중 발견한 장소·위험·채집 지점을 내 말로 남기고, 지도에서 다시 찾아 그 위치로 길안내를 받는다.
  - 기존 애드온과 역할이 다르다 → TomTom 은 도착하면 사라지는 길안내, HandyNotes 는 공용 POI 데이터라 편집 대상이 아니다.

## 공통 제약

여러 기능에 걸친 제약과 기능 사이 모순은 여기에 모은다.

- `NFR#1` [as-built] 핀·카테고리·설정은 계정 전체가 공유하는 SavedVariables `LorePinDB` 하나에 저장한다 (TOC `## SavedVariables`) → 어느 캐릭터로 접속해도 같은 핀이 보인다.
- `NFR#2` [as-built] 이전 버전이 저장한 `LorePinDB` 를 읽어도 오류 없이 동작한다. 로드 시 없는 키만 기본값으로 채우고 있는 값은 바꾸지 않는다.
  - 이전 버전으로 되돌려도(`release.md` §4) 데이터가 손상되지 않아야 한다 → 키를 지우거나 의미를 바꾸는 변경은 하위 호환 방법을 스펙에 먼저 적는다.
- `NFR#3` [as-built] 문구는 enUS 를 기본으로 두고, 클라이언트 언어가 koKR 이면 koKR 문구로 덮어쓴다 → 번역이 빠진 키는 영어로 보인다.
- `NFR#4` [as-built] 외부 라이브러리 없이 WoW 기본 API 만 쓴다. TomTom 은 설치돼 있을 때만 쓰는 선택 연동이다 (`spec_navigation.md`).

## 제외 범위

- 핀 공유·내보내기·가져오기
- 미니맵 핀 표시
- 사용자 카테고리를 만들고 지우는 화면 (데이터·함수는 `spec_pin.md`)
