- **기능명:** 설정 패널·초기화 (UC6)
- **목적 (Why):** 지도 표시와 핀 한도를 사용자 환경에 맞추고, 데이터를 처음 상태로 돌릴 수 있게 한다.

## 2. 목표 및 범위

### In Scope

- WoW 설정 창(Settings)의 LorePin 패널, 월드맵 표시·아이콘 크기, 최대 핀 수, 핀·설정 초기화

### Out of Scope

- 미니맵 관련 설정 → 미니맵 표시는 제공하지 않는다 (색인 제외 범위)

## 3. 요구사항

### 3.1 사용자 스토리

- `US#6` [as-built] 애드온을 쓰는 플레이어로서, 내 환경에 맞추기 위해, 표시와 한도를 바꾸고 필요하면 초기화하고 싶다 → FR#25~FR#27

### 3.2 기능 요구사항

- `FR#25` [as-built] 로그인 시 WoW 설정 창에 LorePin 패널을 등록한다. `/lp settings` 로 연다.
- `FR#26` [as-built] 설정은 바꾸는 즉시 저장되고, 월드맵 관련 값은 즉시 표시에 반영된다.

  | 설정 | 범위 | 기본 |
  | --- | --- | --- |
  | 월드맵 표시 | 켬/끔 | 켬 |
  | 월드맵 아이콘 크기 | 10~40, 1 단위 | 20 |
  | 최대 핀 수 | 50~2000, 50 단위 | 500 |

  - 최대 핀 수를 현재 핀 수보다 낮춰도 기존 핀은 지우지 않는다 → 새 핀만 막는다 (`spec_pin.md` FR#2).
- `FR#27` [as-built] 초기화는 확인 대화상자를 거친다.

  ```
  When  [모든 핀 초기화] → 확인
  Then  핀이 모두 사라지고 다음 핀 ID 가 1, 설정·사용자 카테고리는 그대로, 지도·목록 갱신
  When  [설정 초기화] → 확인
  Then  설정이 기본값, 핀은 그대로, 패널 값·지도 갱신
  ```

## 4. 데이터 및 API 스펙

- `LorePinDB.settings`: `showOnWorldMap`, `worldMapIconSize`, `maxPins` (기본값은 FR#26 표).
  - 이전 버전이 저장한 `showOnMinimap`·`minimapIconSize` 는 지우지 않고 읽지도 않는다 (`NFR#2`) → 이전 버전으로 되돌리면 그 버전이 다시 쓴다. 설정 초기화는 이 키도 지운다.
