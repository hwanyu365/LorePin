# 설정 스펙

## 1. 개요

| 항목 | 값 |
| --- | --- |
| 문서명 | spec_settings |
| 작성일 / 최종 수정일 | 2026-11-14 / 2026-11-14 |
| 버전 | 1.0 |
| 기준 커밋 ID | 1a40209 |

- **기능명:** 설정 패널·초기화 (UC6)
- **목적 (Why):** 지도 표시와 핀 한도를 사용자 환경에 맞추고, 데이터를 처음 상태로 돌릴 수 있게 한다.

## 2. 목표 및 범위

### In Scope

- WoW 설정 창(Settings)의 LorePin 패널, 월드맵 표시·아이콘 크기, 최대 핀 수, 핀·설정 초기화, 사용자 카테고리 만들기·지우기

### Out of Scope

- 미니맵 관련 설정 → 미니맵 표시는 제공하지 않는다 (색인 제외 범위)

## 3. 요구사항

### 3.1 사용자 스토리

- `US#6` [as-built] 애드온을 쓰는 플레이어로서, 내 환경에 맞추기 위해, 표시와 한도를 바꾸고 필요하면 초기화하고 싶다 → FR#25~FR#27, FR#31
- `US#9` [요구사항] 핀을 내 기준으로 분류하는 플레이어로서, 내장 6개로 부족할 때, 이름·아이콘·색을 정한 카테고리를 만들고 지우고 싶다 → FR#35

### 3.2 기능 요구사항

- `FR#25` [as-built] 로그인 시 WoW 설정 창에 LorePin 패널을 등록한다. `/lp settings` 로 연다.
- `FR#31` [요구사항] 설정 패널 제목은 `LorePin v{TOC ## Version}` 이다. 버전을 읽지 못하면 `LorePin` 만 보인다 → 릴리스마다 코드의 버전 문자열을 고치지 않게 TOC 하나만 둔다.
- `FR#26` [as-built] 설정은 바꾸는 즉시 저장되고, 월드맵 관련 값은 즉시 표시에 반영된다.

  | 설정 | 범위 | 기본 |
  | --- | --- | --- |
  | 월드맵 표시 | 켬/끔 | 켬 |
  | 월드맵 아이콘 크기 | 10~40, 1 단위 | 20 |
  | 최대 핀 수 | 50~2000, 50 단위 | 500 |

  - 최대 핀 수를 현재 핀 수보다 낮춰도 기존 핀은 지우지 않는다 → 새 핀만 막는다 (`spec_pin.md` FR#2).
- `FR#27` [as-built] 초기화는 확인 대화상자를 거친다.

  ```
  When  [모든 핀 초기화] → 확인
  Then  핀이 모두 사라지고 다음 핀 ID 가 1, 설정·사용자 카테고리는 그대로, 지도·목록 갱신
  When  [설정 초기화] → 확인
  Then  설정이 기본값, 핀은 그대로, 패널 값·지도 갱신
  ```

- `FR#35` [요구사항] 설정 패널의 사용자 카테고리 영역에서 만들고 지운다 (데이터 규칙은 `spec_pin.md` FR#33·FR#34).
  - 목록: 사용자 카테고리마다 아이콘·이름·색 견본·[삭제]. 없으면 "사용자 카테고리 없음".
  - 만들기 줄: 이름 입력, 아이콘 선택(목록 12개, 기본 첫 번째), 색 견본(누르면 WoW 색 선택기, 기본 흰색), [추가].
    - FR#33 판정을 통과하지 못하면 [추가] 가 막히고, 마우스를 올리면 이유가 툴팁으로 보인다 (`spec_pin.md` FR#28 과 같은 방식).
    - [추가] 뒤 이름 칸은 비고, 아이콘·색은 기본값으로 돌아간다. 채팅창에 "카테고리 추가됨: {이름}".

  ```
  When  [삭제], 그 카테고리 핀 N 개 (N ≥ 1)
  Then  "{이름} 카테고리와 핀 N 개를 삭제합니다" 확인 대화상자 → 확인하면 FR#34
  When  [삭제], 핀 없음
  Then  "{이름} 카테고리를 삭제합니다" 확인 대화상자 → 확인하면 FR#34
  Then  (둘 다) 채팅창에 "카테고리 삭제됨: {이름} (핀 N 개)", 영역 목록·지도·목록 패널 갱신
  ```

## 4. 데이터 및 API 스펙

- `LorePinDB.settings`: `showOnWorldMap`, `worldMapIconSize`, `maxPins` (기본값은 FR#26 표).
  - 이전 버전이 저장한 `showOnMinimap`·`minimapIconSize` 는 지우지 않고 읽지도 않는다 (`NFR#2`) → 이전 버전으로 되돌리면 그 버전이 다시 쓴다. 설정 초기화는 이 키도 지운다.
