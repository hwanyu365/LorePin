# 핀 목록 스펙

## 1. 개요

| 항목 | 값 |
| --- | --- |
| 문서명 | spec_list |
| 작성일 / 최종 수정일 | 2026-11-14 / 2026-11-14 |

- **기능명:** 핀 목록·검색·카테고리 필터·정렬 (UC4)
- **목적 (Why):** 핀이 많아지면 지도를 넘겨 가며 찾을 수 없다 → 모든 지도의 핀을 한곳에서 찾는다.

## 2. 목표 및 범위

### In Scope

- 전체 핀 목록, 검색, 카테고리 다중 필터, 정렬, 행에서 상세 패널·길안내

### Out of Scope

- 지도별 필터 (지도는 정렬 기준으로만 쓴다)

## 3. 요구사항

### 3.1 사용자 스토리

- `US#4` [as-built] 핀이 많은 플레이어로서, 원하는 핀을 빨리 찾기 위해, 검색·필터·정렬되는 목록을 원한다 → FR#17~FR#20

### 3.2 기능 요구사항

- `FR#17` [as-built] 목록은 조건에 맞는 핀 수를 보여 주고, 하나도 없으면 빈 목록 안내를 보인다. 행은 카테고리 아이콘, `[id] 제목`, 지도 이름·생성일(YYYY-MM-DD)이다.
- `FR#18` [as-built] 검색과 카테고리 필터를 함께 적용한다 (둘 다 만족).

  ```
  Given 검색어가 있다
  Then  제목·메모에 검색어가 대소문자 구분 없이 글자 그대로 들어 있는 핀만
  Given 카테고리를 하나 이상 골랐다
  Then  고른 카테고리 중 하나인 핀만. 하나도 안 골랐으면 전체
  ```

- `FR#19` [as-built] 정렬은 최신순(생성 시각 내림차순, 기본)·오래된순·지도순(`mapID` 오름차순, 같으면 최신순)이다.
- `FR#20` [as-built] 행을 좌클릭하면 상세 패널이 열린다. [요구사항] 우클릭도 같다 → 편집은 상세 패널이 맡는다. 행의 [웨이포인트]·[TomTom] 버튼은 `spec_navigation.md` 를 따른다.
- 검색어·필터·정렬은 목록을 닫았다 열어도 같은 접속 안에서 유지된다 (저장하지 않음).
