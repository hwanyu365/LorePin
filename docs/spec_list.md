# 핀 목록 스펙

## 1. 개요

- **기능명:** 핀 목록·검색·카테고리 필터·정렬 (UC4)
- **목적 (Why):** 핀이 많아지면 지도를 넘겨 가며 찾을 수 없다 → 모든 지도의 핀을 한곳에서 찾는다.

## 2. 목표 및 범위

### In Scope

- 전체 핀 목록, 검색, 카테고리 다중 필터, 정렬, 행에서 상세 패널·길안내, 고른 핀의 카테고리 일괄 변경·일괄 삭제

### Out of Scope

- 지도별 필터 (지도는 정렬 기준으로만 쓴다)

## 3. 요구사항

### 3.1 사용자 스토리

- `US#4` [as-built] 핀이 많은 플레이어로서, 원하는 핀을 빨리 찾기 위해, 검색·필터·정렬되는 목록을 원한다 → FR#17~FR#20, FR#36
- `US#10` [요구사항] 핀을 정리하는 플레이어로서, 사용자 카테고리를 지우기 전에 핀을 옮겨 두거나 필요 없는 핀을 한꺼번에 치우기 위해, 목록에서 여러 핀을 골라 카테고리를 바꾸거나 지우고 싶다 → FR#37~FR#39

### 3.2 기능 요구사항

- `FR#17` [as-built] 목록은 조건에 맞는 핀 수를 보여 주고, 하나도 없으면 빈 목록 안내를 보인다. 행은 카테고리 아이콘, `[id] 제목`, 지도 이름·생성일(YYYY-MM-DD)이다.
- `FR#18` [as-built] 검색과 카테고리 필터를 함께 적용한다 (둘 다 만족).

  ```
  Given 검색어가 있다
  Then  제목·메모에 검색어가 대소문자 구분 없이 글자 그대로 들어 있는 핀만
  Given 카테고리를 하나 이상 골랐다
  Then  고른 카테고리 중 하나인 핀만. 하나도 안 골랐으면 전체
  ```

- `FR#19` [as-built] 정렬은 최신순(생성 시각 내림차순, 기본)·오래된순·지도순(`mapID` 오름차순, 같으면 최신순)이다.
- `FR#20` [as-built] 행을 좌클릭하면 상세 패널이 열린다. [요구사항] 우클릭도 같다 → 편집은 상세 패널이 맡는다. 행의 [웨이포인트]·[TomTom] 버튼은 `spec_navigation.md` 를 따른다.
- 검색어·필터·정렬은 목록을 닫았다 열어도 같은 접속 안에서 유지된다 (저장하지 않음).
- `FR#36` [요구사항] 카테고리 필터는 여러 개를 고르는 드롭다운이다 → 사용자 카테고리 개수에 제한이 없어도 목록 머리 폭이 그대로다.

  | 고른 카테고리 | 드롭다운 글자 |
  | --- | --- |
  | 없음 | 전체 |
  | 1개 | 그 카테고리 이름 |
  | 2개 이상 | 카테고리 {n}개 |

  - 펼친 목록은 맨 위 [전체](고른 것이 없으면 체크) 뒤에 카테고리마다 한 줄이다. 줄은 `[아이콘] [카테고리 색 이름] … [체크 상자]` 이고 체크 상자는 오른쪽 끝이다 (저장소 소유자 결정).
  - 카테고리를 누르면 체크가 바뀌고 목록이 바로 다시 걸러진다. 펼친 목록은 닫히지 않는다 → 여러 개를 이어서 고른다.
  - [전체] 를 누르면 고른 것을 모두 해제한다.

- `FR#37` [요구사항] 목록 행의 맨 왼쪽(아이콘 앞) 체크 상자로 핀을 고른다. 하단 줄은 `선택 N개`·[모두 선택]·[선택 해제]·[카테고리 변경 ▼]·[선택 삭제] 다 (저장소 소유자 결정).

  ```
  When  [모두 선택]
  Then  지금 목록에 보이는 핀을 모두 고른다
  When  검색·필터로 고른 핀이 목록에서 빠진다
  Then  그 핀은 선택에서도 빠진다 → 보이지 않는 핀은 바뀌거나 지워지지 않는다
  When  고른 핀이 0개
  Then  [선택 해제]·[카테고리 변경]·[선택 삭제] 가 막힌다
  ```

  - 선택은 목록을 닫았다 열어도 같은 접속 안에서 유지된다 (검색어·필터와 같음, 저장하지 않음).
  - 체크 상자를 눌러도 상세 패널은 열리지 않는다.
  - 변경·삭제는 확인을 누르는 시점에 아직 선택에 남은 핀만 대상이다 → 확인창이 떠 있는 동안 검색·필터로 목록에서 빠진 핀은 바뀌거나 지워지지 않는다.
- `FR#38` [요구사항] [카테고리 변경 ▼] 에서 카테고리를 고르면 확인 대화상자 "선택한 핀 N개의 카테고리를 {이름}(으)로 변경합니다" 를 거쳐 고른 핀의 카테고리를 바꾼다.
  - 바꾼 핀마다 `updatedAt` 을 갱신하고, 지도·목록은 한 번만 갱신한다. 없는 카테고리 ID 면 거부한다.
  - 바꾼 뒤 채팅창에 "핀 N개의 카테고리를 {이름}(으)로 변경", 선택을 해제한다.
- `FR#39` [요구사항] [선택 삭제] 는 확인 대화상자 "선택한 핀 N개를 삭제합니다" 를 거쳐 고른 핀을 지운다.
  - 핀마다 `spec_pin.md` FR#9 와 같이 지도 표시·TomTom 웨이포인트를 정리하고, 지도·목록은 한 번만 갱신한다.
  - 지운 뒤 채팅창에 "핀 N개 삭제됨", 선택을 해제한다.
