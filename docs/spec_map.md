# 월드맵 표시 스펙

## 1. 개요

| 항목 | 값 |
| --- | --- |
| 문서명 | spec_map |
| 작성일 / 최종 수정일 | 2026-11-14 / 2026-11-14 |
| 버전 | 1.0 |
| 기준 커밋 ID | 1a40209 |

- **기능명:** 월드맵 핀 표시·툴팁·클릭 (UC3)
- **목적 (Why):** 핀은 지도 위치에 붙어 있어야 의미가 있다 → 보고 있는 지도에 그 지도의 핀을 겹쳐 보여 준다.

## 2. 목표 및 범위

### In Scope

- 월드맵에서 보고 있는 지도의 핀 표시, 툴팁, 클릭 시 상세 패널

### Out of Scope

- 미니맵 표시
- 상위·하위 지도로 핀 투영 (핀은 저장한 `mapID` 의 지도에서만 보인다)

## 3. 요구사항

### 3.1 사용자 스토리

- `US#3` [as-built] 지도를 보는 플레이어로서, 기록한 곳을 한눈에 보기 위해, 월드맵에 핀이 보이길 원한다 → FR#14~FR#16

### 3.2 기능 요구사항

- `FR#14` [as-built] 월드맵이 열려 있고 월드맵 표시 설정이 켜져 있으면, 보고 있는 지도와 `mapID` 가 같은 핀만 그 좌표에 아이콘으로 보인다.

  ```
  Given 지도 A 에 핀 2개, 지도 B 에 핀 1개
  When  월드맵에서 지도 A 를 본다
  Then  핀 2개만 보인다
  When  지도 B 로 바꾸거나, 핀을 만들기·고치기·지우기 한다
  Then  표시가 즉시 바뀐다
  When  월드맵 표시 설정을 끈다
  Then  핀이 보이지 않는다
  ```

  - 아이콘은 카테고리 아이콘에 카테고리 색을 입힌다. 카테고리를 찾지 못하면 물음표 아이콘·흰색이다.
  - 아이콘 크기는 월드맵 아이콘 크기 설정을 따른다.
- `FR#15` [as-built] 핀에 마우스를 올리면 제목·카테고리(카테고리 색)·메모(있을 때)·좌표(0~100, 소수 1자리) 툴팁이 같은 글꼴 크기로 보인다.
- `FR#16` [as-built] 핀을 클릭하면 그 핀의 상세 패널이 열린다.
